## How to add a reference

For each reference, record:
1. Exact app/site/game name.
2. Direct URL.
3. Which bill's game board game/module it informs.
4. The specific behaviors or qualities worth studying.
5. Any explicit things not to copy, such as proprietary branding, artwork, wording, or distinctive visual identity.

A reference is an interaction/design target, not a request for pixel-for-pixel copying.
